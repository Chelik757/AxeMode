# CheloviyMode (AxeMode)

Мод для Minecraft (NeoForge), который добавляет в игру новые инструменты и ресурсы.

## 📖 Описание
На данный момент мод добавляет:
* **Секиру** (Great Axe) — мощное оружие/инструмент.
* **Платину** — новый ресурс, включающий руду и слиток.
  * Руда генерируется в мире (в обычных и глубоких слоях камня).
  * Слиток можно получить переплавкой руды.

## ⚠️ Статус разработки
Мод находится в активной стадии доработки. Возможны баги и изменения в балансе.
**Текущая версия:** `1.1.0-alpha`

## 🛠️ Техническая информация
* **Версия Minecraft:** 1.21.1
* **Загрузчик:** NeoForge (21.1.265+)
* **Java:** 21

## 📥 Установка
1. Установите [NeoForge](https://neoforged.net/) для Minecraft 1.21.1.
2. Скачайте `.jar` файл мода из раздела [Releases](https://github.com/Chelik757/AxeMode/releases).
3. Поместите файл в папку `mods` вашего клиента/сервера.
4. Запустите игру.
